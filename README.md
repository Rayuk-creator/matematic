# Matematica in gioco · Maths at Play

Gioco di matematica per la scuola primaria (classi 1ª–5ª): mondi, minigiochi, calcoli in colonna passo per passo e verifiche finali di ogni modulo.

- Versione italiana: `index.html`
- English version: `english.html`

Funziona in Chrome su tablet, computer e telefono, anche senza connessione dopo il primo caricamento della pagina. I progressi dei bambini restano salvati solo nel browser del dispositivo: il gioco non raccoglie né invia dati.
